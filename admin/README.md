# Admin OS

Use this checkout for ad hoc company administration, forms, document lookup, and SnapTask photo tasks.

- [Connections](connections.md): accounts, Dapier CLI access, and authentication status.
- [Document index](documents.md): bank, VAT, and company source documents.
- [Ramp](services/ramp.md): reusable vendor-request procedure.
- [Gmail](services/gmail.md): search and read DataTalks.Club emails through Dapier.
- [Drive](services/drive.md): find shared company records and read bank/VAT sources.
- [Slack moderation](services/slack.md): match screenshot identities and deactivate community members.

Keep reusable instructions and source references here. Report task outcomes and approvals in chat. Use ignored `work/` only for temporary private files, then remove them after use; retain no task traces in the repository.

The existing SnapTask application remains in `backend/`, `cli/`, `deploy/`, and `web/`.
