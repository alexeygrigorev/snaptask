03 / START WORKING

One capture. An open-ended queue.

Install the CLI, add your token, and pull your first task. Your agents can use the same API.

curl -fsS https://snaptask.dtcdev.click/cli/snaptask.py -o snaptask.py
python3 snaptask.py --url https://snaptask.dtcdev.click login
python3 snaptask.py tasks list
python3 snaptask.py claim --agent my-agent
python3 snaptask.py download <task-id> --directory ./captures
python3 snaptask.py complete <task-id> --claim-token <claim-token> --result "Finished"

Save the task ID and claim_token returned by claim. Renew long-running work with the heartbeat command before the 15-minute lease expires.

Or call the API directly:

curl https://snaptask.dtcdev.click/api/tasks \
  -H "Authorization: Bearer YOUR_API_TOKEN"
